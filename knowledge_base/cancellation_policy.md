# NovaCart Cancellation Policy

Document Type: Policy
Category: Order Cancellation
Version: 1.0
Last Updated: 2026-08-01

## Cancellation Eligibility

Customers may request cancellation while an order is in:

- Processing
- Confirmed
- Packed

Cancellation is not guaranteed after an order has entered the shipped
stage.

## Shipped Orders

Once an order has been shipped, the customer may not be able to cancel it.

The customer may instead need to receive the product and follow the
applicable return or refund procedure.

## Cancellation Request

A cancellation request should include the order ID.

The system should verify the current order status before determining
whether cancellation is possible.

## Cancellation After Payment

If an order is successfully cancelled after payment has been captured,
the applicable refund process will be initiated according to the payment
and refund policies.

## Failed Orders

Orders with a failed status do not require cancellation.

If payment was nevertheless captured for a failed order, the payment issue
should be investigated separately.

## Exceptions

Cancellation exceptions require human review.

The AI assistant should not guarantee cancellation if the order status
does not permit automatic cancellation.
